# IdeaGenie 🧠✨
### AI-Powered Business Idea Generator

IdeaGenie turns random thoughts into structured, market-validated business ideas using Agentic AI.  
Built for students, founders, and researchers who struggle with "What should I build next?"

**"From Brainstorm to Business Plan in 60 Seconds"**

---

## 🎯 The Problem
Coming up with ideas is easy. Validating them and knowing how to build them is hard.  
IdeaGenie solves this by combining AI generation + market analysis + actionable planning in one app.

## ✨ Key Features
- **Multimodal Input**: Generate ideas from Text, Voice, Image/Sketch, or 2026 Market Trends
- **Agentic AI Processing**: Multi-step AI workflow analyzes feasibility, market demand, and competition
- **Smart Analytics Dashboard**:
    - Impact Score & Feasibility Score
    - Innovation Matrix: Quick Wins, Moonshots, High Impact, Research
    - Predictive Trend Analysis
- **Implementation Roadmap**: Get phases, timeline, and next steps for any idea
- **Idea Library**: Save, bookmark, and track all generated ideas
- **Modern UI/UX**: Flutter app with dark theme, glassmorphism, and data visualizations



## 🛠️ Tech Stack
- **Framework**: Flutter 3.x, Dart
- **UI**: Material 3, fl_chart, lottie
- **State Management**: Provider / Riverpod
- **AI**: Gemini API / OpenAI API
- **Backend**: Firebase / Supabase for Auth and Database
- **Other**: SharedPreferences for local storage
